# Contributing to Vampire Client

Thanks for your interest in contributing.

1. Open an issue before large changes so the design can be discussed.
2. Fork the repository and create a focused branch.
3. Keep changes small and document user-facing behavior.
4. Run `npm install` and `npm run build` before opening a pull request.
5. Never commit access tokens, Microsoft credentials, private keys, personal data, or local configuration files.

By submitting a contribution, you agree that maintainers may review and include it in this project. No project-wide open-source license has been selected yet; do not assume permission to redistribute the project.
